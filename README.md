
# Rildo Tola | Portfolio

A personal portfolio website built with HTML, CSS and JavaScript to showcase my frontend development projects, skills, education and experience.

## Live Portfolio

[View My Portfolio](https://rildo-tola.github.io/Portfolio/)

## Features

- Responsive layout for different screen sizes
- About Me section
- Skills section
- Education section
- Experience section
- Featured projects generated dynamically with JavaScript
- Project screenshots and expandable feature lists
- Contact links for email, GitHub and LinkedIn
- Mobile navigation
- Keyboard-visible focus states

## Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Git and GitHub
- GitHub Pages

## Featured Projects

### Weather App
A weather application using the OpenWeather API, with city search, weather information, loading and error states, and dynamic interface changes.

### Study Task Tracker
A task management application with task creation, completion, deletion and persistent browser storage using localStorage.

### React Project Showcase
A React application demonstrating reusable components, API integration, user-based filtering, custom hooks, loading and error handling.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rildo-tola/phase-1-portfolio.git
   ```

2. Open the project folder in VS Code.

3. Run `index.html` using Live Server.
